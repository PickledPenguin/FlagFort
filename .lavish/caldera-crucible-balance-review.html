The new five-second charger cooldown removes one of the clearest damage spikes, but it does not solve the whole curve.

Why the latest run failed

The fatal night was already being eased by the fort score, but the two permanent meta inputs overwhelmed that reduction.

Root cause: Caldera unlocks at level 19, yet the adaptive model compares level 26 against level 1. It adds +0.375 for level and +0.300 for gear on every night. By Night 8 the underbuilt-fort adjustment was only -0.113, so the horde still landed at 1.609x before mutation composition did its work.

Approved adjustments

The submitted review feedback has been applied to the game and covered by regression tests.

1

IMPLEMENTED · MEASURE FIRST

Five-second charger cooldown

This directly attacks 2,007 damage in the latest run and 4,900-6,300 in three prior losses. Chargers now walk and melee normally between charges.

  • High confidence fix for repeated breach spikes
  • Preserves the enemy identity and counterplay
  • Collect three fresh Caldera runs before stacking another special nerf
2

IMPLEMENTED

Scale level relative to tier unlock

Campaign pressure now counts levels above the selected tier's unlock level. Level 26 in Caldera contributes +0.105 instead of +0.375 while still gaining +0.015 for every additional level.

  • Unlock-required levels no longer count as surplus power
  • Higher player levels still increase pressure continuously
  • Forest retains its level-1 baseline
3

IMPLEMENTED

Differentiate gear pressure

Each equipped item now has its own cap. Swords use 0.40; helmets, wrenches, and mallets use 0.25. A diamond sword and wrench contribute +0.25 together instead of about +0.30.

  • Offensive sword power remains strongly represented
  • Utility equipment no longer inherits the sword's pressure ceiling
  • Every contribution remains deterministic and capped
4

IMPLEMENTED

Allow negative correction

When pressure exceeds performance, the following night can now receive deterministic relief down to -0.20. Dominant play can still raise pressure by up to +0.55.

  • Responds to collapse instead of merely stopping escalation
  • Uses the existing finalized prior-night metrics
  • The modest floor preserves each tier's identity
5

IMPLEMENTED

Reduce Cinderburst damage by 10%

All Cinderburst blast targets now receive 90% of the previous damage, including the player, flag, and every structure type.

  • Preserves radius, falloff, burn, and placement counterplay
  • Applies consistently to every blast target
  • Covered by an end-user-style combat death regression test
6

UNCHANGED AS INTENDED

Keep compound mutations

The offensive mutation combinations remain unchanged per review feedback.

  • No shared offensive mutation cap added
  • No repeated-pick weakening added
  • Fresh runs can isolate the effects of the approved changes

Next validation runs

The approved package is implemented. Fresh Caldera runs should now measure whether the intended difficulty curve has landed.

1

Replay

Run Caldera three times with normal experienced play. Track charge damage, burst damage, multiplier, survivors, and destroyed structure value.

2

3
