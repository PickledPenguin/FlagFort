What changed

The work stays concentrated in shared engine, registry, UI, and render paths. Focused tests cover each risky gameplay transition.

Navigation

Clean obstacle exits

Blocked start cells now choose the nearest collision-safe open cell using the actor’s exact world position. Resource clusters and constructed detours use the same shared grid behavior.

Targeting

Priority-driven ranged AI

Projectile specials retarget through shared priority metadata. Comet Slingers use Player, Turret, Flag. Aether Gunners retain valid structure-aware detours.

Clockwork

Deterministic rewind reset

The existing presentation is preserved. The broken boss returns at half health beside a seed-selected valid portal while the Night 10 schedule restarts without awarding phantom kills.

Enemy Codex

Registry-backed tactical view

Compact colored icon stats, actual target order, richer traits, campaign-tier sorting, accurate copy, and preserved modal scroll all derive from gameplay definitions.

Campaign UI

Shared Forest introductions

Forest Frontier’s seeded roster now matches its card. Enemies sharing an introduction night appear together with centered names, smaller portraits, and one shared night label.

Rendering

Explicit harvester layers

Other structures render first, then every harvester arm, then harvester bodies. The ordering is exposed as a small testable renderer helper.

Rewind state transition

The state reset happens only after the established freeze, reverse countdown, and merge presentation completes.

Presentation updates

Small UI changes align the menu, Codex, boss art, and campaign card with existing FlagFort conventions.

Briar Behemoth

The Forest Frontier boss replaces “The Boss” across player-facing registry data. Its editable layered SVG now has a thornwood crown, four arms, and a simple vine plate while staying deliberately plainer than later bosses.

Vertical menu actions

Upgrades, Shop, and Enemies retain their button dimensions and style in one 172 px column, including the low-height layout.

Overflow-safe Codex

Six stat icons reflow from six to three to two columns. Target chips shrink responsively and collapse to centered icon labels on narrow screens.

Browser QA note: Live Chrome inspection confirmed the updated Comet Slinger Codex content and no horizontal overflow at 960×540 before the browser binding became unavailable.
