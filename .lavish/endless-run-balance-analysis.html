The campaign works. Endless mode stops fighting back.

The first 10 nights create rising attrition and a credible boss climax. Endless mode then allows turret count, damage, fire rate, and range to stack together faster than enemy durability or composition can answer. The result is a portal-to-portal kill field, not a fort defense.

Primary diagnosis: multiplicative turret scaling plus weak late-wave composition, amplified by a boss-wave correction bug.

Recommended balance package

Cap the solved build, then add smarter pressure

These changes are intended as one package. Enemy buffs alone would preserve the degenerate build and punish every other build more severely.

Bound turret scaling

Keep turrets powerful, but stop all four scaling axes from growing forever.

  • Cap total turret capacity at 8 for the first tuning test.
  • Cap temporary turret damage at +90% and rate at +60%.
  • Cap temporary range at +60%, about 816 units with the current permanent bonus.
  • Remove capped cards from the offer pool instead of presenting dead choices.

Fix late-wave composition

Spend endless threat budget on tactical pressure, not hundreds of identical basics.

  • Scale special per-wave and simultaneous caps after night 10.
  • Reserve at least 30-40% of threat for non-basic enemies.
  • Deterministically add unused roster counters every five endless nights.
  • Prioritize archers and acidslingers when turret coverage or turret share is extreme.

Rebuild boss-night flow

A boss should cap the assault, not cancel most of it.

  • Spawn the boss after the ordinary assault is substantially deployed.
  • Require both the boss and scheduled wave to be cleared.
  • Give endless bosses an explicit cycle-based health and pressure curve.
  • Exclude never-spawned schedule entries from corrective performance telemetry.

Add deterministic endless escalation

Every five nights, introduce one authored pressure rule: an added counter-enemy, elite affix, split portal assault, or boss modifier. Use purpose-specific seeded RNG so replay behavior stays stable.

Create resource sinks, not upkeep chores

Thousands of banked resources show the economy also stops making decisions. Prefer optional high-cost emergency abilities, consumable fort powers, or mutually exclusive structure specializations over passive maintenance taxes.

Protect player agency

Once turrets dominate, the player contributes zero kills and almost no building or gathering time. Add targets that reward active interruption, expose temporary weak points, or disable a defense lane until the player responds.

Validation plan

Measure threat quality, not just enemy count

Replay the same seed first, then use a small deterministic seed suite. The first pass succeeds only if pressure returns without breaking the campaign's night 1-10 curve.

Evidence and interpretation notes

This is one normal-difficulty seed and one highly turret-focused strategy, so exact tuning values are first-test targets rather than final balance constants. The diagnosis is still high confidence because the code and telemetry align: upgrade effects stack without general caps, special enemy caps remain fixed, the active-enemy cap is 90, adaptive health influence is low, and the selected roster excludes explicit turret-targeting archers.

Telemetry kill counts can exceed scheduled spawn counts because summons are included. Boss nights are also structurally different because killing the boss can end the run phase early. Night 47 is marked partial because the run was manually ended, even though all 504 spawned enemies were cleared.

Recommended implementation order: cap turret scaling and correct card-pool behavior, then scale special composition and rebuild boss flow, then re-run this seed before tuning adaptive coefficients. Changing adaptive numbers first would hide the underlying multiplicative problem.
