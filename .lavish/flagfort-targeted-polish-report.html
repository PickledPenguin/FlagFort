What changed

Pause and run settlement

COUNT FROZEN + PAUSED; nested coin boxes
Now: one centered Pause heading and a spacious, flat coin summary with only the outcome emphasized.

Music lifecycle

A superseded crossfade could orphan an older track.
Now: the manager owns every live track, retires superseded audio, and prevents stale phase music from surviving rapid transitions.

Base boss

Could stop for the player; Ground Slam repeated near the flag; five reinforcements.
Now: marches toward the flag while meleeing nearby players, charges one half-health Ground Slam, and raises ten basics when it lands.

Acidslinger

Nearby disposable structures could become targets even when off-route.
Now: selects turret, player, or flag normally and attacks structures only when shared path geometry identifies a real obstruction.

Boss balance

Ordinary zombie difficulty multipliers were applied directly to bosses.
Now: both bosses use softer boss-specific curves for health, damage, speed, and attack speed. Frost Warden armor scales with the same health curve.

Snow popup contrast and copy

Light feedback could disappear on snow; several enemy descriptions were stale.
Now: a shared luminance-aware resolver darkens light popup colors in snow while preserving outlined frost blue. Boss, Summoner, and Acidslinger copy matches behavior.

Each card lists health, damage, speed, and attack-speed multipliers. Adaptive difficulty, challenges, mutations, and endless-cycle scaling still compose afterward through the existing stat pipeline.
